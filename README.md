# 🗑️ Smart Bin Alert App

Smart Waste Bin Alert App built with MIT App Inventor. IoT-based demo project to monitor waste bin level and alert when full.

### ✨ Features
- 📊 Simulates bin fill level (0-100%)
- 🚨 Alerts when bin is 80% full
- 🔴 Red indicator when bin is full, 🟢 Green when empty
- 🔔 Popup notification alert
- 🔊 Voice alert using Text-to-Speech (TTS)
- ♻️ Reset button to empty bin

### 🛠️ Built With
- MIT App Inventor
- Android

### 📂 Files in this Repo
- `Smartbinapp.aia.zip` -> Source code (Import in MIT App Inventor)
- `Smartbinapp (1).apk` -> Installable Android App

### 📲 How to Use
1. Download the `.apk` file and install on Android phone
2. Open the app
3. Press "Fill Bin" to increase level
4. At 80%, you will get RED alert + Voice alert

### 🎯 Use Case
IoT Smart City project - Can be connected with ultrasonic sensor in real dustbin to alert municipality.
